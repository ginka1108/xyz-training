# XYZトレーニング 紹介動画（Remotion）

横長 1920×1080・30fps・約41秒（X などの SNS 告知用）。左に手牌、右に Z の入力パレット。言葉は最小限で、操作の流れだけを見せる。

| 場面 | 内容 |
|---|---|
| タイトル | 「Xを引いたらYを切ってZ待ち」ロゴ |
| 聴牌 | 13枚＋ツモX → Yをタップ → 待ちZを3つ選んで決定 → ○100 |
| 連続設問 | 同じ13枚で3問。毎回ふつうに X を見て Y を切り、Z を選んで決定。2問目以降は手牌が出たまま X だけ入れ替わる |
| 二向聴 | 受け入れ7種を次々に選ぶ。時間超過で点が 100→94 に減る |
| 今日の10問 | ボタン → 合計点と ○×△ |
| 締め | ロゴ |

## 使い方
```bash
npm install
npm run data        # 問題データを mahjong.js から作り直す（シード固定なので毎回同じ）
npm run studio      # プレビュー（http://localhost:3000）
./render.sh         # out/xyz-training.mp4 を書き出す
```
- フォルダ名に日本語が入っていると書き出しが止まるので、`render.sh` は一時フォルダにコピーしてから書き出す。
- フォントは動画で使う文字だけのサブセット（`public/fonts`）。文言を変えたら `fetch-fonts.mjs` の `chars` に足して `node fetch-fonts.mjs`。
- 場面の長さは `src/Root.tsx` の `LEN`、動きは `src/scenes.tsx`。
